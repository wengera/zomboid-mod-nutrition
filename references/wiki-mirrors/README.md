# Wiki mirrors

Structured excerpts of PZwiki pages we depend on, kept so page edits/deletions
can't erase our sources. Each file header carries the source URL, retrieval
date, and the page's last-modified stamp at retrieval.

**License/attribution:** PZwiki content is published under
CC BY-NC-SA (see pzwiki.net site notices). These excerpts are attributed,
non-commercial, and share-alike accordingly. If any part of this library ever
goes public, these files and their attribution ride along under that license.

Mirrors are *excerpts* (structure, facts, link lists), not pixel-perfect
copies. If a full snapshot is ever needed, save the page via browser alongside.
