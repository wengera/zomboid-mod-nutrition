> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the design phase's jar, platform and compatibility research in the library so that Plans 1–9 cite register rows and never a report: every claims-candidate line of the fourteen non-science reports and the six controller notes minted once as a row on a new or updated page under the § 3 gates, the supersessions spec § 9 names carried through every page that tags them, the sixteen new experiments named, and the area pages, skills, wall map and roots updated. **Architecture:** Four serial tasks on shared files first — the delta applier's one-child `supersede` op and a provisional-tag flag for the page lint; the inventory tool's surface census written to a new dated dataset; the experiments in two families. Then Wave C, fifteen page tasks in parallel on disjoint files (eight new facts and platform pages, one new teardown, six update tasks over eleven existing pages), each writing its page with provisional tags and a delta file; a single wave-close commit applies every delta, indexes the wave's open rows and re-renders the generated sections. Then Wave D, seven area and reference tasks in parallel (one new area page with its skill), the same close, one serial roots task that also rewrites the one rule line four pages share, and the program close. The binding page procedure is `docs/superpowers/plans/2026-09-27-plan-0-page-procedure.md` Part A.

**Tech Stack:** Python 3.13 standard library (`tools/`, `pytest`), Markdown pages under the page contract, the claims register `docs/reference/claims.tsv` through `tools/claimslib.py`, `tools/claims_check.py`, `tools/claims_delta.py`, `tools/page_lint.py`, `tools/mod_inventory.py`, `tools/workshop_search.py`; the jar toolchain `C:\Users\Angus\pz-b42\pz.sh` (read-only) for re-location.
