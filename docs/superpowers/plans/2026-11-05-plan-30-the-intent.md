# Plan 30: the intent — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a survival agent that acts with intent: it sneaks past zombies that have not noticed it, never stands while its model thinks, treats a zombie behind a door as a decision, swings at a chaser only once it is inside a tile and never backs off a swing that did nothing, resolves a stall into an approach or a walk, and rides a dressing through a far flee under a fast bleed; read live over two sessions on kills, hits per kill, the minutes standing near zombies and the minutes sneaking.

**Architecture:** the harness Lua (`testing/PZAgent/PZAgent/42/media/lua/client/`: the motor `PZAgent_Motor.lua`, the sense list `PZAgent_Sense.lua`, the hello in `PZAgent_Main.lua`, the melee reflex `PZAgent_StanceMelee.lua`) under PZA/1.9 (one command, two `me` fields, three zombie fields); the Python planner under `testing/agent/base/planner/` (`maneuvers/melee.py`, `dispatch.py`, `goal_runner.py`, `goal_policies.py`, `goal_prompt.py`, `fight.py`, `edges.py`, `threat.py`, `hold.py`, `care_yield.py`, `policies.py`, `survive.py`); new grades `grades/e21.py` and `grades/f12.py` (one module per grade, frozen per artifact, copying the live names it reads, P26-Q); the agent page split into `docs/platform/agent-sessions.md`; thin chain and LLM drivers copied under their own keys; two jar reads minted as rows.

**Tech Stack:** Python 3 (pytest, the fakes, lupa for the Lua tests and the decision-golden replays), Kahlua Lua (`kahlua_lint.py`, `luabalance.py`), `tools/pza_schema.py`, the `claude` CLI for the LLM source, the register tools (`claims_check.py`, `claims_delta.py`, `page_lint.py`, `reference_gen.py`), `C:\Users\Angus\pz-b42\pz.sh` for the jar.
