# Nutrition Revamp — compatibility

Release 1.0.0, game build 42.21 and newer, with the game-feel and pre-upload changes made before the first upload (see `CHANGELOG.md`): nothing about a character changes while its player is offline, records are kept for good with a backup copy on the character (`NR.RecordKeepDays` is removed), a body clock sets hunger's daily rhythm with sleep on, a long fast follows the science, and the server refuses an eat at the top Overfull level in Managed mode. The mod claims no stat hook: in Managed mode (the default) it sets vanilla's hunger, thirst and fatigue rates to zero at server start and writes those stats once a game minute, so another mod's write to one of them lasts until the next minute's write. A sweep of 234 installed mod folders on 2026-09-30 found no mod that claims the server's stat-update hook; every collision found is a second writer of a stat or a wrap chain that composes. The stances below are the mod's design. The `evidence` column names what backs each one: a dedicated-server run by its run id, a read of the neighbour's code, or `unread` where the neighbour's code has not been read and the stance is as designed.
